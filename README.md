Ein kleines Projekt in Java mit Spring Boot, HTML und Thymeleaf.
Der Rechner berechnet anhand der Widmark-Formel den theoretischen Blut-Alkoholwert einer Person nach der 
Einnahme bestimmter Getränke (hier Bier, Wein, Vodka, Korn und Whiskey)
Ich beschränke mich bei der Berechnung auf Personen über 18.
Dieser Rechner sollte natürlich AUF KEINEN FALL zur ernsthaften Berechnung genutzt werden und dient
lediglich der Übung.
